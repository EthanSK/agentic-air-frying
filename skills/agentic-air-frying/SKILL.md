# Agentic Air Frying

Lead with what goes in each drawer. Plan for one load with no mid-cook additions, turning, or shaking when the food directions and the desired result allow it. Keep the user's involvement low by making safe, clearly stated assumptions and asking only for details that materially change the plan.

## Start with the food the cook has

For a new dinner or stock question, use the cook’s authorised recent grocery orders and any available meal or leftovers notes before asking them to list ingredients. If their setup has iPhone Mirroring, check their own signed-in Zapp or Zoom by Ocado app as described in [connected setup](references/connected-setup.md). Treat purchases as clues to what may be left. If lookup is unavailable, use the receipt, package or ingredients the cook supplies.

When a meal used food from a multi-serving pack and the portion is unknown, keep the remaining amount uncertain. If the amount matters for the next meal or stock estimate, ask whether they used the whole pack or have some left. Include vegetables they have on hand when planning a meal.

## Plan the load

1. Establish the exact food and its state (fresh, chilled, or frozen), amount, approximate thickness, and desired result. Use details already supplied. Check the exact product's package or manufacturer directions when available. Identify the fryer model or known drawer layout if that affects what fits or which functions can be used.
2. Group foods only when their required heat, timing, airflow, and handling are compatible. Leave room for air to circulate and stay within the model's capacity. Prevent cross-contamination, including drips between shelves or onto ready-to-eat food. Use a separate drawer, separate batch, or another appliance when foods cannot share the same conditions safely.
3. Choose each drawer's mode, temperature, and time from the best available directions. Prefer the food's air-fryer instructions. If using oven directions to estimate an air-fryer plan, name it as an adaptation and state the assumptions and when to check. Never apply a fixed oven-conversion or full-basket multiplier.
4. Confirm any finish-together function in the manual for that exact model. If the model supports staggered starts with independent settings, use that feature when appropriate. Otherwise explain the timing trade-off and give the simplest workable sequence. Make any required preheat, turn, shake, or additional batch clear.
5. Give the relevant end check for each food, using the packaging and current local food-safety guidance as needed. Keep the estimated countdown separate from doneness. For foods that require thorough cooking, use a suitable check from authoritative guidance. Surface state alone can be misleading.

See [planning examples](references/planning.md) for shared drawers, single-drawer fallbacks, browning, and care.

## Give a short answer the cook can follow

- Start with the drawer names the cook uses, such as **Top Drawer** and **Bottom Drawer** or **Drawer 1** and **Drawer 2**. Use **Basket** for a single drawer. Give the contents, then the settings for each active drawer. Mark an unused drawer if the user might otherwise enable it.
- Add the finish-together setting or any necessary step and the end check. Say what directions you checked and flag any material estimate. When asked to repeat the plan, repeat the placement alone unless settings are requested or a necessary step would be missed.
- Give a manual plan for any supported layout. When the cook authorises setup and confirms food is loaded, see [connected setup](references/connected-setup.md) for preparing and monitoring a COSORI program through VeSync. The cook presses Start/Pause at the panel.
- Answer timing or browning questions using the actual food and its current state. Treat each reported outcome as evidence about that load and model.
